# Pricing — PDFForge

PDFForge is completely free. All processing runs in the visitor's browser, so there are no server costs and nothing to charge for.

## Free

- Price: $0 (no subscription, no recurring fee)
- Limits: No file limits, no page limits, no daily caps
- Features: All 18 tools (merge, split, compress, convert, rotate, watermark, sign, protect, unlock, page numbers, delete/extract/reorder pages, PDF to text)
- Watermarks: None — output documents are never branded
- Accounts: Not required; fully anonymous usage
- Privacy: Documents are processed locally in the browser and never uploaded

## What you never pay for

- No hidden fees (USD $0 for every feature)
- No premium tier (there is only the free plan)
- No credit card required
- No feature gating

## Guarantees

- Uptime: The tools run in the user's browser via client-side JavaScript and WebAssembly, so they work whenever the page loads regardless of server-side outages.
